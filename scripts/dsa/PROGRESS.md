# DSA course-notes — progress ledger

Turning Pavel Mavrin's _Algorithms & Data Structures_ playlist
(`PLrS21S1jm43igE57Ye_edwds_iL7ZOAG4`, 61 lectures) into a Docusaurus `dsa` section
via the yt-notes pipeline. Branch: `dsa-course-notes` in `system-design-course`.

## Pipeline per lecture
1. `uv run yt-notes ingest "https://www.youtube.com/watch?v=<id>"` (bare URL — never `&list=`).
2. `python3 scripts/dsa/clean_transcript.py <bundle>` → `transcript.clean.md` (de-triplicates captions ~3×).
3. Authoring subagent per `scripts/dsa/AUTHORING_SPEC.md`, matched to exemplar `s01e01`.
4. Consolidated `npm run build`; adversarial reviewer subagents fix code/math/fidelity/links.
